# SQL Business Case Study – Mobile App Market Analysis

## Project Overview
This project focuses on solving real-world business problems using SQL on a mobile app dataset.  
The analysis was performed from a business perspective to derive insights related to app performance, revenue generation, user ratings, data cleaning, and database security.

The project demonstrates how SQL can be used not only for querying data but also for supporting business decision-making.

---

## Dataset Information
The dataset contains information about mobile applications such as:

- App Name
- Category
- Rating
- Reviews
- Installs
- Type (Free/Paid)
- Price
- Genres

---

## Business Problems Solved

### 1. Identified Top 5 Categories for Free Apps
Analyzed average ratings of free apps to determine the most promising categories for launching new applications.

### 2. Revenue Analysis of Paid Apps
Calculated estimated revenue using:
Revenue = Price × Installs

Identified the top 3 revenue-generating categories.

### 3. Percentage Distribution of Gaming Apps
Calculated category-wise percentage distribution of gaming applications.

### 4. Free vs Paid App Recommendation
Compared category ratings to recommend whether companies should focus on free or paid apps.

### 5. Database Price Change Tracking
Implemented a mechanism to track unauthorized changes in app prices during a simulated hacking scenario.

### 6. Data Restoration
Restored correct price data after identifying manipulated records.

### 7. Correlation Analysis
Investigated the relationship between app ratings and number of reviews.

### 8. Data Cleaning for Genres
Cleaned the genres column by separating multiple genres into different columns to improve recommender system performance.

### 9. Dynamic SQL Tool for Underperforming Apps
Created a dynamic query solution where users can input a category and identify apps performing below category average ratings.

### 10. Query Performance Concepts
Studied the difference between Duration Time and Fetch Time in SQL query execution.
